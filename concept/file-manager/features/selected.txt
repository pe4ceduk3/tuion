то есть выделение не слетает при
- нажатии кнопки назад
- входе в содержимое
- в разворачивани деревовидной иерархии
- даже выход из приложения
потому что выделение сохраняется в кэше

- deselect (cancel select)
- cut
- copy
- delete (trash)
- favorite (starred)
- add to (shortcuts)
- rename (multi-rename)
